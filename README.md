# proctan-ai-redirect

Redirects proctan.ai to https://processtangent.ai/. Served as public GitHub Pages from bigandslow/proctan-ai-redirect via `mirror.yml`.

Availability of proctan.ai and www.proctan.ai is monitored by Cloud Monitoring uptime checks on the prod stack of process-tangent/accounting-automation (`infrastructure/src/public-uptime-checks.ts`).
